# Code of Conduct

## Our pledge

We are committed to making participation in Fair Interviews welcoming and respectful for everyone, regardless of background or identity. We aim to make collaboration free from harassment and intimidation.

## Expected behavior

- Be considerate, respectful, and constructive.
- Discuss ideas and behavior, not personal attributes.
- Accept feedback graciously and focus on what is best for the project and its users.
- Respect privacy. Do not publish candidate information, credentials, or other personal data.

## Unacceptable behavior

Harassment, discrimination, personal attacks, sexualized language or imagery, doxxing, threats, and publishing private information without consent are not acceptable. Persistent disruption of discussions or other conduct that would be inappropriate in a professional setting is also unacceptable.

## Scope

This code applies in project spaces, including GitHub issues, pull requests, discussions, and other project-related communications, as well as when someone is representing the project publicly.

## Reporting

Report conduct that violates this code to the project maintainers through GitHub. For security vulnerabilities, use the private reporting instructions in [SECURITY.md](SECURITY.md). Maintainers should review reports respectfully and take appropriate, proportionate action.

This code of conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
